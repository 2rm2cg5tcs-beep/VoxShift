# Pressvppp — изменение голоса в реальном времени

Программа для Windows 10/11: меняет голос с микрофона прямо во время разговора — в Dota 2, CS2, Discord, Steam и любых других программах. Работает в фоне из трея.

## Скачать

**[Pressvppp_Setup.exe](../../releases/latest/download/Pressvppp_Setup.exe)** — установщик (права администратора не нужны).
[Pressvppp_portable.exe](../../releases/latest/download/Pressvppp_portable.exe) — без установки.

> Windows может показать «Windows защитила ваш компьютер» — это обычное предупреждение для программ без платной цифровой подписи: «Подробнее» → «Выполнить в любом случае».

## Первый запуск

Откройте пункт **«Быстрая настройка»**:

1. **Установить VB-Cable** — бесплатный виртуальный микрофон, через который программы слышат изменённый голос. После установки перезагрузите компьютер.
2. **Сделать «CABLE Output» микрофоном по умолчанию** — одна кнопка. Ваш настоящий микрофон программа запомнит сама.

Всё. Выберите голос, закройте окно — Pressvppp останется в трее, а голос будет изменён везде, пока программа запущена. Если в какой-то программе микрофон выбран вручную (Steam → Голос, Discord → Голос и видео), выберите там «CABLE Output».

## Возможности

- 56 готовых голосов: девушка, ребёнок, великан, демон, робот, рация, призрак, пещера, бурундук и другие + свои пресеты.
- Высота голоса и тембр (форманты) настраиваются **отдельно** — женский голос из мужского звучит естественно, а не как ускоренная запись.
- Эффекты: робот, шёпот, вибрато, кольцевой модулятор, перегруз, 8-бит, хор, эхо, реверберация, эквалайзер, фильтры.
- Очистка микрофона: шумодав, подавление шума вентилятора, выравнивание громкости.
- Горячие клавиши работают в игре: **Ctrl+Alt+V** — вкл/выкл, **Ctrl+Alt+PgDn/PgUp** — смена голоса, **Ctrl+Alt+M** — слышать себя.
- **Выйти полностью** (кнопка ⏻ вверху окна, пункт в «Настройках» или в меню значка в трее): программа закрывается целиком, не остаётся в процессах, а Windows снова использует ваш обычный микрофон — как до Pressvppp. При следующем запуске Pressvppp сам вернёт «CABLE Output».
- Задержка ≈ 32 мс обработки, нагрузка 1–4 % одного ядра; в тишине программа «засыпает» (≈0 %).

## Безопасность для игр

Pressvppp не вмешивается в игры: не читает их память и не внедряется в процессы. Для игры это обычный микрофон Windows — так же работают Discord, OBS и Voicemod. Горячие клавиши — стандартная функция Windows `RegisterHotKey`, без перехвата клавиатуры.

## Сборка из исходников

Visual Studio 2022+ и CMake 3.21+:

```
cmake -S . -B build -A x64
cmake --build build --config Release
build\Release\dsp_tests.exe
```

GitHub Actions собирает установщик автоматически при каждом изменении ветки `main` (тесты → сборка → самопроверка → скриншоты интерфейса → Inno Setup → релиз `latest`).

Устройство: `src/dsp` — переносимый звуковой движок (фазовый вокодер с переносом спектральных пиков Laroche–Dolson, раздельные форманты по кепстральной огибающей, эффекты), `src/app` — WASAPI, интерфейс (Dear ImGui + Direct3D 11), трей, горячие клавиши. Сторонние библиотеки в `third_party`: Dear ImGui (MIT), pocketfft (BSD), nlohmann/json (MIT).
